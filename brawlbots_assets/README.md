# Brawlbots (Tanks) - Game Assets & Resources

هذا المجلد يحتوي على جميع موارد وملفات الوسائط الخاصة بلعبة **Brawlbots (الدبابات)**، دون أي أكواد برمجية للعبة.

## المحتويات:
1. **`tanks/`**:
   - جميع موارد وأصول اللعبة الديناميكية المأخوذة وفقاً لـ `__assets.json` الأحدث من سيرفر الموارد (`https://game-assets-prod.platocdn.com`):
     - صور الدبابات والأسلحة والعناصر التجميلية والإكسسوارات (`images/`) بصيغة `.webp` (34 ملفاً بدقة كاملة).
     - المقاطع الصوتية وموسيقى الخلفية واختيار الدبابات (`music/`) بصيغة `.m4a` (ملفان موسيقيان).
   - إجمالي الملفات: 36 ملف مورد ديناميكي مكتمل ومطابق لـ SHA-1 بنسبة 100%.

2. **`static_game_assets/`**:
   - جميع الموارد الثابتة (أشكال، خرائط، مؤثرات بصرية، أصوات، شيدرات، نماذج حركية):
     - ملفات أطلس وهياكل Spine الحركية للدبابات والمؤثرات (`.atlas`, `.json`).
     - ملفات الشيدرات الرسومية (`.glsl`).
     - المؤثرات الصوتية الكاملة (`.m4a`) من طلقات وانفجارات وارتطامات.
     - الأيقونات وواجهة المستخدم، الخرائط (`tiled.json`)، وخصائص الدبابات والأسلحة (`config.toml`).
     - قواميس النصوص واللغات (`dictionary.json`) بما فيها اللغة العربية.
   - إجمالي الملفات: 430 ملف مورد ثابت.

3. **`__assets.json`**:
   - خريطة الربط والتحقق (Manifest) لجميع الـ SHA-1 Hashes للموارد الديناميكية.
