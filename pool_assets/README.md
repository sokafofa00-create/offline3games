# Pool (Billiards / 8-Ball) - Game Assets & Resources

هذا المجلد يحتوي على جميع موارد وملفات الوسائط الخاصة بلعبة **Pool (البلياردو)**، دون أي أكواد برمجية للعبة.

## المحتويات:
1. **pool/**:
   - جميع موارد وأصول اللعبة الديناميكية المأخوذة وفقاً لـ __assets.json الأحدث من سيرفر الموارد (https://game-assets-prod.platocdn.com):
     - صور وأشكال عصي البلياردو والكرات وطاولات اللعب والأطر والملصقات والعناصر التجميلية (imported/) بصيغة .webp (2025 ملفاً بدقة كاملة).
     - المقاطع الصوتية وموسيقى الخلفية وتأثيرات ضرب الكرات وإدخالها في الجيوب (imported/) بصيغة .m4a و .wav (3051 ملفاً صوتياً).
     - الموسيقى الأساسية للبلياردو (	h_basic_music.m4a).
     - ملفات الحركة والفيديو التوضيحي (.mp4 — ملف واحد).
   - إجمالي الملفات: 5077 ملف مورد ديناميكي مكتمل ومطابق لـ SHA-1 بنسبة 100%.

2. **static_game_assets/**:
   - جميع الموارد الثابتة (أشكال، طاولات، مؤثرات بصرية، أصوات، شيدرات، نماذج حركية):
     - ملفات أطلس وهياكل Spine الحركية لعصي وطاولات البلياردو والمؤثرات (imported/*.atlas, imported/*.json) — 123 ملفاً.
     - ملفات الشيدرات الرسومية (shaders/*.glsl) — 3 ملفات.
     - المؤثرات الصوتية الكاملة (sounds/*.m4a) من أصوات ضرب الكرات، الكسر، السقوط في الجيب، وصافرات الفوز — 23 ملفاً.
     - عناصر واجهة المستخدم والمتجر والأزرار (images/ui/, scene-ui/) — 16 ملفاً.
     - صور وثيمات الطاولات والأشكال (images/imported/themes/) — 4 ملفات.
     - الصور الرمزية وإعدادات اللعبة (scene-avatars/, scene-settings/) — 13 ملفاً.
     - قواميس النصوص واللغات (dictionary.json) بجميع اللغات المدعومة بما فيها اللغة العربية الكاملة.
     - ملف المصادقة (ttestation.json).
   - إجمالي الملفات: 184 ملف مورد ثابت.

3. **__assets.json**:
   - خريطة الربط والتحقق (Manifest) لجميع الـ SHA-1 Hashes للموارد الديناميكية.
