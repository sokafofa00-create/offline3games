# Match Monsters - Game Assets & Resources

هذا المجلد يحتوي على جميع موارد وملفات الوسائط الخاصة بلعبة **Match Monsters**، دون أي أكواد برمجية للعبة.

## المحتويات:
1. **`match3battle/`**:
   - جميع موارد وأصول اللعبة الديناميكية والفرعية المأخوذة وفقاً لـ `__assets.json` الأحدث من سيرفر الموارد:
     - صور الوحوش وهياكل Spine والحركات (`monsters/`) بصيغة `.webp`.
     - صور الحلبات والساحات والخلفيات (`stages/`) بصيغة `.webp` و `.png` و `.jpg`.
     - المقاطع الصوتية وموسيقى المراحل (`music/` و `stages/*/music`) بصيغة `.m4a` و `.mp4`.
   - إجمالي الملفات: 500 ملف مورد كامل بنسبة 100%.

2. **`static_game_assets/`**:
   - جميع الموارد الثابتة (أشكال، أيقونات، مؤثرات بصرية، أصوات، شيدرات):
     - ملفات أطلس Spine (`.atlas`).
     - ملفات الشيدرات الرسومية (`.glsl`).
     - المؤثرات الصوتية الكاملة (`.m4a`, `.wav`).
     - الأيقونات وخلفيات واجهة المستخدم.
   - إجمالي الملفات: 524 ملف مورد.

3. **`__assets.json`**:
   - خريطة الربط والتحقق (Manifest) لجميع الـ SHA-1 Hashes للموارد.
